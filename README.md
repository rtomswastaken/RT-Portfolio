## 🚀 Getting Started

### Prerequisites
- Node.js >= 18
- npm >= 9

### Installation & Local Development

```bash
# Clone the repository
git clone https://github.com/rtomswastaken/RT-Portfolio.git
cd RT-Portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
